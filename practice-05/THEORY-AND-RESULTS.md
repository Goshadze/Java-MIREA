# Практика 5 — конспект к защите

## Теория

- Дженерики задают параметр типа: `GenericStack<String>` принимает строки и возвращает их без приведения. Проверка типа выполняется компилятором; `Object[]` внутри стека содержит только значения, переданные через `push(E)`. Параметр `E` стирается при компиляции, поэтому стек создаёт `Object[]`, а в `peek()` приводит элемент к `E` в одном месте. Для примитивов используют классы-обёртки, например `GenericStack<Integer>`.
- При заполнении внутренний массив стека удваивается через `Arrays.copyOf`, элементы сохраняют порядок. Копирование при росте занимает O(n), а последовательность добавлений даёт амортизированное O(1) на `push`. При `pop` ссылка в освобождённой ячейке обнуляется.
- `unique` строит новый `ArrayList`, добавляя элемент только если `contains` его ещё не нашёл. Сравнение производится через `equals`; порядок первых вхождений сохраняется. Для n разных элементов повторные вызовы `contains` дают O(n²).
- Линейный поиск сравнивает элементы по порядку, возвращает индекс первого совпадения или -1. `Objects.equals` позволяет сравнивать и `null`.
- Для максимума задано ограничение `E extends Comparable<? super E>`: `compareTo` сравнивает объекты. Для круга достаточно сравнить радиусы, так как при неотрицательном радиусе большему радиусу соответствует бо́льшая площадь. Ограничение допускает тип, сравнимый со своим супертипом. Обе перегрузки `max` рассчитаны на сравнимые элементы без `null`. Двумерный вариант обходит все строки, в том числе строки разной длины. Если элементов нет, выбрасывается `IllegalArgumentException`.

- Стек работает по принципу LIFO: последним добавлен — первым извлечён. `push` добавляет элемент на вершину, `peek` читает вершину без удаления, `pop` возвращает и удаляет её. `isEmpty` проверяет пустоту, `getSize` возвращает размер.
- В композиции `MyStack` **содержит** список `ArrayList` как поле (`has-a`). В наследовании `InheritedStack extends ArrayList<Object>` сам является списком (`is-a`). Последний вариант дополнительно открывает все публичные операции `ArrayList`, в том числе вставку в середину; поэтому для ограничения интерфейса стека композиция обычно удобнее.
- `ArrayList` хранит элементы в порядке добавления. Вершина стека находится по индексу `size() - 1`. `pop` удаляет последний элемент. Для `peek` и `pop` пустого стека явно выбрасывается `EmptyStackException`.
- `Object` позволяет хранить значения любых ссылочных типов; примитивы вроде `int` автоматически упаковываются в соответствующие классы-обёртки. Для работы с полученным элементом конкретного типа может потребоваться приведение типа.
- `Cloneable` — маркерный интерфейс. Он разрешает защищённому методу `Object.clone()` начать копирование полей. Ссылки копируются как значения, поэтому при поверхностной копии оба стека указывали бы на один список. [Java API: Object.clone()](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/lang/Object.html#clone())
- `MyStack.clone()` после `super.clone()` создаёт новый `ArrayList` из исходного. Поэтому добавление или удаление элемента в одной копии не меняет другую. Самостоятельный список — глубокая копия **поля списка**, но его элементы копируются как ссылки: изменяемый элемент остаётся общим. Копировать произвольные `Object` целиком универсально нельзя без дополнительного контракта.
- `InheritedStack.clone()` использует `ArrayList.clone()`, который создаёт отдельное внутреннее хранилище, сохраняя ссылки на те же элементы. `super.clone()` возвращает копию фактического класса, поэтому приведение к `InheritedStack` корректно.
- `CloneNotSupportedException` проверяемое. В `MyStack` оно обрабатывается в `catch`; при реализации `Cloneable` этот путь не ожидается и сигнализируется через `AssertionError`.

## Что сделано и результат

1. Алгоритмы удаляют дубликаты, ищут элемент и максимумы; отдельный обобщённый стек удваивает массив, а другой наследует ArrayList.
2. `MyStack` с полем-списком реализует все операции из таблицы. UML обеих реализаций приведена в README.
3. Клиент запрашивает пять строк один раз и извлекает их методом `pop` из двух унаследованных вариантов: `InheritedGenericStack<String>` и `InheritedStack` (второй вариант `MyStack` из задания).
4. Клон `MyStack` получает собственный список. В клиенте исходник `[первая, вторая]` не меняется после превращения копии в `[первая, копия]`.

Пример: если ввести по строкам `один`, `два`, `три`, `четыре`, `пять`, программа выведет их в порядке `пять`, `четыре`, `три`, `два`, `один`.
