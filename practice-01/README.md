# Практическая работа №1

Синтаксис Java, типы данных, арифметические выражения, структуры выбора, основы ООП.

## Задания

**Task 1 & 2** — Конвертация валют (юани → рубли)
- YuanToRoubles.java — базовая конвертация
- YuanToRoublesEnding.java — с правильным окончанием слова "юань"

**Task 3 & 4** — ООП (класс Car)
- Car.java — класс с конструкторами, геттерами, сеттерами, методом getAge()
- Main.java — демонстрация работы с объектами

## Запуск

```fish
cd src/task\ 1\ and\ 2 && javac *.java && java YuanToRoubles
cd ../task\ 3\ and\ 4 && javac *.java && java Main
```
