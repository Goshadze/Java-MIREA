# Java

Учебный репозиторий для практических работ по Java (ПНЯД).

## Структура

Каждая практическая работа — отдельная папка `practice-NN/` с исходниками в `practice-NN/src/`
и кратким описанием заданий в `practice-NN/README.md`.

```
Java/
├── practice-01/        # Практическая работа №1: синтаксис, типы данных, if/else, ООП
│   ├── README.md
│   └── src/
├── practice-02/        # заготовка для следующей практики
└── ...
```

Файлы внутри `src/` — обычные `.java`-классы без пакетов (по одному публичному классу на файл),
это соответствует стилю задач курса (простые консольные программы в IntelliJ IDEA).

## Как открыть в IntelliJ IDEA

1. `File -> Open` -> выбрать папку `Java` (эту).
2. Для каждой `practice-NN/src` можно пометить папку как **Sources Root**
   (ПКМ на папке -> `Mark Directory as -> Sources Root`), тогда IDEA будет видеть классы
   всех практик и позволит запускать нужный `main` через правый клик -> `Run`.
3. Либо создавать отдельный модуль IntelliJ на каждую практику — как удобнее.

## Как собрать/запустить из терминала (без IDE)

```fish
cd practice-01/src
javac *.java
java Main   # или конкретный класс с методом main
```

## Добавление новой практики

```fish
mkdir -p practice-NN/src
```

и положить туда `.java`-файлы + `README.md` с условием задания.
