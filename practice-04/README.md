# Практическая работа №4

ООП в Java: абстрактные классы, интерфейсы, сравнение объектов и исключения.

В `src/geometry` выполнены задания о фигурах: `Triangle`, проверяемое исключение `IllegalTriangleException`, сравнение площадей через `Comparable<GeometricObject>` и `max`, круги, прямоугольники, интерфейс `Colorable` и массив фигур. `ComparableCircle` наследует `compareTo()` от `GeometricObject`: повторно реализовывать `Comparable` с другим параметром типа в Java нельзя.

В `src/months` выполнены два задания после теории: массивы месяцев и количества дней, проверка целого числа и обработка выхода за границы массива; для февраля запрашивается год, учитываются правила високосного года.

[Конспект к защите](THEORY-AND-RESULTS.md)

### Запуск из этой папки

```fish
./run.sh
```

Выберите 1 или 2. Для треугольника введите три стороны, цвет одним словом и `true` или `false`. Разделитель дробной части зависит от локали Java.
